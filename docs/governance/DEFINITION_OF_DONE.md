# Definition of done

A milestone passes only with all applicable exit criteria: correct branch/base; working implementation; resolved imports; validated normal, invalid and missing inputs; error handling; meaningful passing tests; no secrets; current branch README/checklist/graph; scope validation; meaningful commit; push to the current remote branch; remote HEAD verification; no unrelated writes; main untouched.
M0 is documentation-only, so application imports/startup and business tests are not applicable. Graph consistency and scope validation are applicable. Local files alone do not constitute a delivered milestone.
