# Methods and boundaries

Conversation state is principal/session scoped with a 24-hour lifetime. Each turn reauthenticates and reauthorizes; selections are not authority. Location/product choices come from observed authorized records. Context includes period, country/timezone, product, category, metric, variants, chart preference and forecast horizon. Optional local model classification accepts only an allowlisted intent at confidence >=0.85; deterministic tools supply all reported facts. The classifier is a fallback, not broad language-understanding certification.

Sales arithmetic uses Decimal. Comparisons require complete daily coverage in both periods for every included store/product. Missing observations are not zero. Heuristic daily-unit thresholds are -40% LOW_SALES, -20% DECLINING, +20% STRONG; an observed stockout/risk flag overrides a low-demand interpretation. Snapshot availability cannot prove intraday availability or causality. Recommendations include product, location, period, observed facts and a reason; no prices, orders, purchases or refunds are executed.

Taxonomy is configurable and preserves raw values. Product 360 exposes observed attributes and unknown fields. Distinct products with indistinguishable names receive stable display ordinals; names are not invented. Chart specs come from the same selected observations as text. ECharts renders category, time, multi-series, heatmap and scatter views locally with accessible data tables. Long charts require narrower selections.

Forecasting uses observed units as a demand proxy: naive, 7-day moving average, exponential smoothing, seasonal naive and weekday means where history permits. Candidates are compared on common chronological rolling one-step folds; minimum history is 14 contiguous days ending at the requested origin with consistent product coverage. Selection ranks MAE, then RMSE. WAPE is unavailable for zero actual volume. Historical cutoff prevents future observations from entering training. Scores used to select the winner are not an independent holdout estimate. RMSE-scaled bands are heuristic, not calibrated confidence intervals. No price/promotion causal model, ETS/SARIMA claim or proven real-data accuracy is made.

Competition compares internal products in the same observed apparel family. Configured weights cover category, family, gender, color, price proximity and store overlap, normalized over observed factors. Coverage and factors are exposed. Similarity is a heuristic, not substitution probability. There is no external competitor feed.

Diagnostic responses compose analytics, inventory observations, pricing context and the existing pricing agent when a product is selected, forecast, internal competition and configured market calendar. Where available, existing signed, scoped RAG supplies policy evidence; missing local configuration is explicit. Historical RAG/agent security tests remain in the full suite. Original operational agents are called for scoped orders, returns, pricing, supply and support; their evidence is shown in the response. Forecasts and recommendations are advisory.

Concurrency: run a single application worker for the in-process conversational turn lock. Current catalog reads and all-history forecasts are intended for bounded local datasets; database-scale query pushdown, distributed state coordination and production load qualification remain future deployment work. Options are capped at 1,000; the UI filters the returned options. No claim is made of arbitrary-scale semantic search or unrestricted natural-language parsing.

Diagnostic category/store peers exclude the selected product and measure observed product/store/day units within authorized selected locations, period and variant filters. Counts and missing peers are disclosed; comparisons do not prove causation or complete coverage. Duplicate product names require a choice. Windows uses declared tzdata for IANA rules.
